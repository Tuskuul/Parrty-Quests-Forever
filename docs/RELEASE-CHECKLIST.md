# Party Quests Forever 1.1.7-alpha5 build record

Parchment readability: all five native difficulty categories have context-specific light/dark tints. Dark paper lifts red, orange, green and gray while preserving yellow; light paper uses dark red/orange/ochre/green/gray ink. Muted, ready and error labels are brighter on dark paper, with a one-pixel dark shadow. Copy/Import fields remain dark ink. Beta's normal standalone window and joined/native tracker keep their existing palettes; alpha's parchment pop-out follows the paper palette.

Settings: the actual control panel now lives in an addon-owned movable MEDIUM host that raises on open; native Settings retains a separate launcher category. No native Settings frame is restyled or reparented. Sharing windows have a settings shortcut and top-level click raising. The settings host is not registered as a UIPanel and all non-modal sharing windows now use MEDIUM strata below native map borders. Leaving the native launcher uses Blizzard Close(true), respecting unapplied-settings confirmation, rather than changing native frame strata. Existing combat deferral remains. Opening settings preserves share-window state, selected quests and text drafts.

Validation: full Lua source/regression checks and auto-tag tests for each branch; representative light/dark parchment contrast comparisons for all five categories; actual host coexistence/raising and gear shortcut tests. Live client verification: palette appearance at selected brightness, gear placement, drag/close/reopen settings beside each sharing window and open/close the native map with settings/share/Copy windows open, preserved Copy/Import text and selection.

The original intermittent map-marker clipboard taint and combat blocked-action reports remain unresolved. This build does not claim to fix them. Main is unchanged.
