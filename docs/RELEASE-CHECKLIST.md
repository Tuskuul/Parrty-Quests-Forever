# Party Quests Forever 1.1.7-beta2 build record

Adds read-only Questie docking and collision-aware map share-button placement on beta only. Main 1.1.6 and alpha6 remain unchanged. Existing normal settings remain in SimplyPartyQuestsDB; legacy alpha settings are retained separately.

Docking uses named Questie_BaseFrame and Questie_HeaderFrame geometry, converted into UIParent coordinates. The party sidebar and its backdrop stay parented/anchored only to addon-owned frames/UIParent; no Questie or native tracker scripts, anchors, module lists, settings or children are modified. Initialization/handoffs wait until outside combat. Once independent, the pane may follow read-only geometry and render its own rows during combat. Dock collapse is independent, preserves the outside-combat preference and allows manual reopening. Native repair/combat restrictions remain in force while Questie owns the native UI. Invalid/hidden targets, insufficient screen space and render errors fall back to the existing standalone window. Error retry is bounded.

The map control scans a bounded visible frame subtree for small title-bar buttons, reads their rectangles and shifts only our own control left until clear. Scans are throttled while the map is visible; combat defers placement. A completely full title bar hides this shortcut, leaving existing tracker/settings share access.

Validation: 28 source files syntax-checked, 27 Lua regression suites, 8 automatic-tag tests. New suites cover read-only foreign-frame isolation, both sides, UI scale, drag/resize geometry, screen edge/no-room fallback, independent combat collapse/reopen, auto-collapse opt-out, saved preference restoration, minimize/hidden/missing targets, normal popout mode, map collision with multiple/scaled buttons, stable placement and hidden-map/combat deferral. Existing rendering, combat, sharing and native guard suites remain green.

Live verification required: Questie 12.11.0 with tracker enabled; party pane alignment while dragging/resizing Questie and at different UI scales; Questie header at top/bottom and minimized; left/right choices and screen edges; scrolling, Share, Settings and hide/show; combat with pane open and closed, manual reopen and preference restoration; toggle Questie's tracker and select separate-window mode. Inspect map Share Quest Log alongside the previously overlapping button in normal/maximized map modes. Report blocked actions, Lua errors, unreadable text or clipping. Mocked tests do not establish live secure execution or every third-party layout.
