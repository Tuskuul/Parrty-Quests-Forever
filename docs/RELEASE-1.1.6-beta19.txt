Party Quests Forever 1.1.6-beta19

- Improved red, orange, yellow, green and gray quest-title contrast on parchment, with brighter status labels and subtle text shadows on dark paper.
- Settings opens in a movable window alongside quest and sharing windows. Added a settings button to sharing windows.
- Party Quests windows no longer use the dialog layer, allowing the map and other game panels to open normally alongside them.
- Parchment brightness still updates open windows immediately without changing selections or Copy/Import text.

For WoW Forever 1.60.1 (interface 16001). Existing settings are preserved.
